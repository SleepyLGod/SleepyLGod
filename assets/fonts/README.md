# Dancing Script

`DancingScript.ttf` is the variable Dancing Script font from Google Fonts:
<https://github.com/google/fonts/tree/main/ofl/dancingscript>.

It is redistributed under the SIL Open Font License in `OFL-DancingScript.txt`.
`scripts/build_header.py` converts the greeting to SVG outlines using fonttools.
The README therefore needs no web font, font CDN, or particular system font.
